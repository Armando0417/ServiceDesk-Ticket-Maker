# Ticket Autofill — Standard

This is the recommended focus-based ServiceDesk autofill extension. Load the ticket JSON from the clipboard, then focus or tab through the ServiceDesk fields that should be filled.

It also handles workday ticket exports initiated by the Ticket Generator.

## Install

1. Open `edge://extensions` or `chrome://extensions`.
2. Enable **Developer mode**.
3. Choose **Load unpacked**.
4. Select the `Edge_extension` folder.
5. Disable `Edge_extension_alt` if it is installed.

Only one Ticket Autofill extension should be enabled at a time.
